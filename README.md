# VELOOP Rewards

A modern and responsive rewards platform UI built using React.js and Vite.

## Project Overview

VELOOP Rewards is a promotional rewards interface containing multiple interactive banners for different reward features.

The project focuses on creating a premium, modern and user-friendly UI with subtle animations and interactive elements.

## Tech Stack

- React.js
- Vite
- Bootstrap
- CSS Modules
- React Icons
- JavaScript
